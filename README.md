# grigorio lag

Otimizador de ping e FPS para jogos (feito do zero).

- **grigorio-lag-usuarios.exe**: app para quem recebeu login e senha.
- O app procura atualizações sozinho ao abrir.

Aviso: a otimização de rede usa um driver de captura de pacotes (WinDivert). Jogos com anti-cheat podem estranhar; use por sua conta e risco.
